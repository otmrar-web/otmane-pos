# 🛒 Otmane POS

Application de caisse **Point de vente (POS)** développée en **C# avec .NET et Windows Forms**.

Ce projet permet de gérer les principales opérations d'un commerce : produits, panier, ventes, paiements et reçus.

## ✨ Fonctionnalités

- Gestion des produits
- Gestion du panier et des quantités
- Recherche de produits
- Historique des ventes
- Gestion des clients
- Calcul automatique de la TPS et de la TVQ
- Paiement avec Stripe
- Paiement par terminal (TPE)
- Paiement comptant
- Impression des reçus
- Lecture des codes-barres

## 🛠️ Technologies utilisées

- C#
- .NET
- Windows Forms
- SQL Server
- Stripe API

## 🗄️ Base de données

L'application utilise **SQL Server** pour enregistrer et gérer les données liées aux produits, aux ventes et aux paiements.

## 💳 Paiements

Intégration de **Stripe** pour tester et gérer différents scénarios de paiement.
